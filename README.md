# 딸깍 장바구니품의서

쇼핑몰 장바구니에서 선택한 상품을 추출해 **품의서용 품목내역**, **원인행위용 물품내역**, **품의개요**, **원인행위개요**를 빠르게 만드는 정적 웹앱입니다.

## 지원 쇼핑몰

- 쿠팡
- G마켓
- 11번가
- 이마트몰(SSG)
- S2B

## 개인정보·데이터 처리

장바구니에서 추출한 데이터는 서버에 저장하지 않습니다. 데이터는 URL hash를 통해 새 탭으로 전달된 뒤 즉시 주소에서 제거하고, 작업 복구를 위해 현재 브라우저의 localStorage에만 임시 저장합니다.
